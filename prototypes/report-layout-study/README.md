# HTML 报表布局方案

从 `index.html` 打开三个方案的比较页。全部资源在本目录，无远程依赖；可直接打开 HTML，也可通过本地 HTTP 服务预览。

- A `a-workspace.html`：侧栏工作台，左目录和右内容独立，适合扩展硬件分类。
- B `b-journal.html`：双层导航报表，目录与时间栏分行，保留连续长报表。
- C `c-focus.html`：模块专页，切换分类时更换正文，适合模块深链。

顶部原型切换条属于比较工具，不属于正式产品。网页未模拟 macOS 标题栏；内容布局从 WebView 可用区域顶部开始。导航和时间栏放在滚动容器外，不依赖滚动事件或图表渲染来显示。窄窗口下导航换行，时间控件独立换行。

交互包括模块导航、范围切换、自选日期和校验、规格展开、复制、外观切换、演示快照刷新。所有值均为演示夹具；历史筛选影响历史示例，不修改设备快照。刷新不会读取本机。没有实现真实数据采集、导出或诊断算法。

应用真实 WebKit 标题栏与正式报表生命周期的集成需在选定方案后验证；此原型不构成当前 WebKit 首屏问题的根因确认。既有 `prototypes/report-redesign/` 保持原样。
