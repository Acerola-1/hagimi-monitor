自定义排序

所有模块行与指标格支持长按拖动排序，拖起时浮起预览、落点实时归位；也可右键（触控板双指轻点）呼出菜单，按上下左右逐格移动，顺序随时可恢复。

数据统计

运行数据分层聚合入库，在原生数据报表中查看趋势曲线、热力图、健康评分与历史走势；需要时也可导出独立 HTML 文件。

工具和显示器

锁键盘、防止休眠、屏幕保持常亮。外接屏的亮度、音量和对比度从这里拉。

两个版本，如何选择

GitHub 直连版功能完整；App Store 版受沙盒限制，部分功能不可用。

  • 功能GitHub 直连版App Store 版
  • 八大监控模块（CPU / GPU / 内存 / 存储 / 网络 / 电池 / 蓝牙 / 显示器）有有
  • 数据统计 · 健康评分 · 事件检测（原生报表）有有
  • 快捷功能（键盘锁定 / 防休眠 / 不息屏）有有
  • 双主题 · 多种菜单栏样式有有
  • 面板长按拖动排序 · 右键方向移动有有
  • CPU / 内存 TOP 进程列表有有
  • 存储 / 网络 TOP 进程列表有无
  • 温度传感器与风扇转速读取有无
  • 显示器控制（亮度 / 音量 / 对比度 · 媒体键）有无

由于 App Store 沙盒限制，部分功能无法在沙盒环境中正常工作，因此功能不完整。
