# 原生宿主尺寸回归验证

本轮仅处理电源分页闪烁/高度跳动和显示器滑杆同时抖动的反馈，不代表全模块迁移或视觉验收完成。

## 可复现的协议缺陷

- `PanelCardLayout` 已按完整自然高度测量明细，摆放却仍给旧视口的零高度提议。离屏原生回归在 180、70、240、90 四种分页高度都记录到 `0`。
- `NativePanelNodeGroup` 未将当前层左右内衬应用于传给子宿主的内容宽度。离屏回归在数值更新前后都读到父宽度 320，而扣除内衬后的实际内容宽度是 300；替换页内容更新使用环境宽度，随后布局使用实际宽度，形成不一致的尺寸输入。
- 修正原生明细的摆放高度，并逐层传递实际内容宽度。旧视口继续保留零高度提议，不改解析运动参数、采样或显示器控制后端。

## 检查结果

- 修正前，`NativePanelHostingTests` 两项新回归失败；旧视口兼容测试通过。
- 修正后，宿主、原生运动、几何、布局、滚动、显示器控制引擎的 67 项定向测试通过。
- Direct Release 和 App Store Debug 构建通过，两份独立预览签名核验通过并在后台启动；安装版未替换。
- `openspec validate migrate-panel-to-native-layer-motion --type change` 和差异格式检查通过。
- 日志及预览回执：`tmp/panel-fix-2026-10-01/`。其中 `baseline-result.json` 保存旧代码失败信息，`fixed-tests.log` 保存定向回归，`preview-receipt.json` 登记产物哈希和运行身份。

真实分页切换、材质闪烁和物理鼠标拖动由用户继续验收；本轮未操作用户桌面、录屏或执行压力测试。离屏回归只证明上述尺寸协议缺陷已修正，不能证明反馈中的所有可见瑕疵已消失。4.3、4.5 及完整验收任务继续保持未完成状态。

## 后续反馈：短页切长页闪烁

用户确认显示器滑杆已正常，并指出电源进程排名页切换到任何较高页面都会闪烁，反向切换正常。原宿主每次将 NSHostingView 的 frame 改成新页高度，导致内容承载层反复缩小/扩容；承载外壳增大还会作废并重播旧的遮罩计划。

电源顶层宿主现在按当前面板/屏幕容量预留承载高度，保持内容层尺寸，登记及运动继续使用真实自然高度。其他模块不启用该预留策略。新增的原生宿主扩容测试在修正前失败，修正后通过；完整面板集成回归确认预留容量未被误报为页高度。合计 69 项相关回归及双渠道构建通过。
