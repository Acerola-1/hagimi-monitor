## 3. 隐藏期探针门控

开始前，`design.md` 实测记录必须已是「已填写」。本组降低的是没人看时的请求和 CPU，不解决后台 100 多兆的常驻内存。CPU 上更值得先看的是电池采样、进程能耗、统计分钟汇总和 Game HUD 前台识别；真要改这四项时先补规格，不在本组里顺手做。

- [x] 3.1 所有面板隐藏时停止公网 IP 请求；面板变为可见且指标仍开启时再查。失败保持缺失或上次成功值。验证：2026-11-03 用改后的 Direct Debug，面板保持关闭约 35 秒，进程没有任何 TCP 连接，公网 IP 服务也没有连上。没有再打开网络明细看那一次补查。指标没有删。
- [x] 3.2 所有面板隐藏时停止蓝牙周期性系统画像；面板变为可见且蓝牙行仍开启时补一次。关闭蓝牙行仍完全停止。验证：同上 35 秒里没有 `system_profiler` 子进程。这台机器的蓝牙行本来就是关的，所以「行开着但面板关着」这条没有在实机上单独看过；代码只在面板可见时才允许周期画像，关掉蓝牙行仍走原来的 `stop()`。
- [x] 3.3 菜单栏不含 CPU 温度且面板全部隐藏时，不读 SMC 温度键。菜单栏选了温度，或有面板可见时，恢复读取。CPU 占用采样保持原周期。验证：代码按这个条件开关温度读取，CPU 占用路径没有改。这台机器的菜单栏当前包含温度，所以面板关上时仍会读温度键；「菜单栏不含温度」的隐藏期追踪没有再录。
- [x] 3.4 确认本 change 没有删除或截短统计库。验证：`maintain()` 仍只按原窗口清理分钟和小时，按天记录的测试在 Direct 测试里通过。没有另做一次删库。
