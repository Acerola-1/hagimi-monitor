# idle-probe-gating

## Purpose

规定面板全部隐藏时，哪些采样必须继续、哪些因为当时没有人看而必须停下。菜单栏正在显示的读数和风扇告警保持原样。

## ADDED Requirements

### Requirement: 菜单栏读数保持原有节奏
面板全部隐藏时，菜单栏当前选中的指标 SHALL 继续按现有周期更新。CPU 占用 SHALL 继续采样。本能力 SHALL NOT 拉长菜单栏已经在显示的数值的刷新间隔。

#### Scenario: 面板关闭后面板图标仍在动
- **WHEN** 所有面板都隐藏，且菜单栏正在显示 CPU 占用
- **THEN** CPU 占用继续按原周期更新

#### Scenario: 不拖慢已显示的菜单栏温度
- **WHEN** 菜单栏当前包含 CPU 温度
- **THEN** 温度继续按原周期更新，即使面板全部隐藏

### Requirement: 风扇告警不随面板隐藏停止
面板全部隐藏时，风扇采样 SHALL 保持常驻。停转或过载告警 SHALL 仍能发出。本能力 SHALL NOT 把风扇采样改成只在面板可见时运行。

#### Scenario: 面板关闭后风扇停转仍通知
- **WHEN** 所有面板都隐藏，且机器有风扇并发生停转
- **THEN** 告警仍按现有风扇规则发出

### Requirement: 隐藏时不查询公网 IP
所有面板都隐藏时，应用 SHALL NOT 向第三方地址查询公网 IP。公网 IP 指标 SHALL 保留，用户仍可在网络明细里开关。任一面板变为可见且该指标开启时，SHALL 再发起查询。关闭时仍在飞的回调 SHALL 失效，不得继续尝试备用源、不得清除重开后新一轮请求的在飞状态。查询失败时 SHALL 保留上一次成功结果或缺失占位，不得显示伪造地址。

#### Scenario: 面板关闭不再出网查 IP
- **WHEN** 所有面板都隐藏，且距上次公网 IP 查询已超过原刷新间隔
- **THEN** 不再请求第三方 IP 服务

#### Scenario: 打开面板后恢复查询
- **WHEN** 公网 IP 指标开启，且一个面板从隐藏变为可见
- **THEN** 发起一次公网 IP 查询，并用结果或缺失占位更新该指标

#### Scenario: 旧查询晚到不影响重开
- **WHEN** 关闭面板时旧公网 IP 查询仍在飞，随后面板重新打开
- **THEN** 重开立即启动新查询，旧查询的成功或失败回调不得清除新查询状态

### Requirement: 隐藏时不跑蓝牙系统画像
所有面板都隐藏时，应用 SHALL NOT 为蓝牙电量启动周期性的系统画像进程。蓝牙行仍被用户勾选时，连接和断开事件 SHALL 可以继续更新内存中的设备状态。任一面板变为可见且蓝牙行仍开启时，SHALL 再跑一次画像。用户关闭蓝牙行时，SHALL 继续完全停止蓝牙采样。

#### Scenario: 面板关闭不再周期拉起画像
- **WHEN** 蓝牙行开启，且所有面板都隐藏
- **THEN** 不再按原周期启动系统画像进程

#### Scenario: 打开面板补一次画像
- **WHEN** 蓝牙行开启，且一个面板从隐藏变为可见
- **THEN** 启动一次系统画像，并用成功结果更新设备电量；失败时保留上次成功结果

#### Scenario: 旧画像未结束时重开
- **WHEN** 关闭面板时旧系统画像仍在飞，随后面板重新打开
- **THEN** 重开只排队一次补查，并在旧画像结束后立即执行

### Requirement: 菜单栏不用温度时隐藏期不读温度键
菜单栏未以指标文字模式显示 CPU 温度、主面板全部隐藏、且 Game HUD 未在显示温度时，应用 SHALL NOT 为温度读取 SMC 温度键。此期间 CPU 占用采样 SHALL 继续。菜单栏改回指标文字模式并显示温度、任一面板变为可见，或 Game HUD 显示且勾选 CPU 温度时，SHALL 恢复温度读取。无 SMC 的渠道 SHALL 保持温度缺失，不得填入猜测值。

#### Scenario: 所有温度消费者都不需要温度
- **WHEN** 菜单栏指标不含 CPU 温度、所有面板隐藏，且 Game HUD 未使用温度
- **THEN** 不因每秒采样去读 SMC 温度键

#### Scenario: 打开面板恢复温度
- **WHEN** 直连版可以读取 SMC，且一个面板变为可见
- **THEN** 温度读数恢复更新

#### Scenario: Game HUD 需要温度
- **WHEN** Game HUD 正在显示且勾选 CPU 温度，同时所有主面板隐藏、菜单栏不显示温度
- **THEN** 温度读取保持原节奏，HUD 不得把门控期间保留的缓存温度作为首帧实时读数

### Requirement: 缓存温度不进入统计
门控关闭期间为展示而保留的旧温度 SHALL NOT 被当作新的温度观测写入统计聚合。统计中的 CPU 温度 SHALL 只来自真实执行的 SMC 读取。

#### Scenario: 面板关闭后温度停止观测
- **WHEN** 所有温度消费者都不再需要温度，门控停止读取 SMC
- **THEN** 统计记录器不再累计新的温度样本，保留的历史数据不删除

### Requirement: 不删除统计历史
本能力 SHALL NOT 删除统计库、应用日聚合或用户尚未清除的按天历史。分钟和小时数据 SHALL 继续使用现有保留窗口。

#### Scenario: 优化后历史报告仍在
- **WHEN** 用户在实施本能力之前已经积累了按天统计
- **THEN** 这些按天记录仍可在统计报表中打开
