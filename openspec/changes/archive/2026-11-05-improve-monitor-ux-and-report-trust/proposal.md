# 让监控面板可操作、报表状态可判断

## Why

三轮审查发现了无名设置开关、告警露出内部键、缺风扇历史却显示零转速等问题。2026-11-04 的定向复核还在原生面板上观察到 CPU 辅助激活没有展开、工具子浮层内点击使未钉住父面板消失，以及临时面板空闲时 Esc 未收起，已经可以把改动范围限定到具体操作与宿主。

## What Changes

- 首先修复设置/分页业务名称、告警文案、历史风扇状态、电源分页对比及存储/报表读取状态（U01/03/04/09/10）。
- 改善分页命中与标签、快捷工具入口说明、公开实验行、指标复制反馈及跨窗口类别色（U02/06/07/08/11）。
- 为全局快捷键录制增加冲突保护，为当前报表接入打印和导出菜单（U17/20）。
- 对 CPU 行头建立可验证的辅助激活与键盘展开路径（U16）；修正未钉住快捷面板的父子点击边界及活动临时面板的 Escape 处理（U18/19）；为登录项明确失败分支提供可恢复反馈（U21）。
- 共 16 个实施主题。U05 首次发现、U12 评分误读、U22 旧系统 Control-click 留作外部取证，不在本 change 编码。既有暂缓 U13/15/23 和拒绝 U14 维持原裁决。七项复核记录与复开条件见 [design.md](design.md)。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `settings-window` — 设置开关命名、入口可见性、外观选项、快捷键保护、登录项与存储读取状态。
- `monitor-panel` — 紧凑分页、行头激活与指标复制。
- `fluid-menu-bar-panel` — 快捷面板子浮层的点击归属及分层取消。
- `report-data-accuracy` — 告警时段与硬件文案、风扇历史、快照状态与跨窗口图例语义。
- `html-report-export` — 前台报表的文件菜单与键盘命令。

## Impact

涉及共享 SwiftUI 面板、AppKit 窗口事件、设置、原生报表、字符串目录与相关测试。沿用现有两渠道、配色、指标宽度登记、采样口径、偏好域和导出实现。按独立批次实施，不引入数据库迁移或新依赖。[综合审查](../../../docs/reviews/2026-11-04-ui-ux-synthesis.md) · [原阶段计划与 QA 矩阵](../../../docs/reviews/2026-11-04-ui-ux-plan.md)
