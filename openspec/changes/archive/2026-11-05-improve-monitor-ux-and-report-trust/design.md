# 实施设计与待验证项裁决

## Context

复核日期 2026-11-04，源码 `d855b7d3`，macOS 27.2（26B123）。使用上轮由该基线 Direct Debug 复制、改名并临时重签的 HagimiNativeUXAudit.app，独立偏好域。窗口、辅助树及事件均绑定隔离实例，复核结束后已退出。以下是对原审查的增量证据，未跑构建、测试或完整发布矩阵。

**复演要点。** 普通面板用实际状态项左键打开；CPU 上的默认辅助动作要同时核对 AX 结果、明细节点和画面。快捷面板用同一隔离包，以 `HAGIMI_PANEL_TEST_HOST=pinned` 启动再按应用重开路径进入现有快捷宿主；不设 BENCH，确认标题动作是“钉住面板”。需要时用 `HAGIMI_PANEL_TEST_DISPLAY` 指向当时主屏。先保持未钉住，再点钉住作对照，确认“取消钉住”。这个入口测试了实际面板控制器，不代表真实全局快捷键登记已经验收。键盘探测含进程级导航偏好，未改变系统辅助设置。U18 的观测足以确认用户后果，尚不足以区分点击监听和失去 key 中哪一条先执行。

## Goals / Non-Goals

固定范围为 16 个实施主题。验收按“输入 → 操作 → 可观察结果”记录，优先在现有控件、窗口和数据提供边界内修复。首次使用者研究、旧系统事件分流、全局材质、报表评分算法、采样、数据迁移及 HUD 新能力均在范围外。旧系统仍属兼容验收范围，缺旧设备不得勾选相应验收项。

## Decisions

1. **报表先分清输入，再显示数值。** 在 ReportThermalView 消费已有聚合结果，按已知硬件能力、可读性、时段数据顺序分支。保留真实零。ReportAppsView 将起止时间合为与目录签名一致的本地化范围，分别覆盖进行中与跨日。ReportPowerView/ReportThermalView 只改本次触及的用户文案。
2. **两条读取链独立收口。** StatisticsRecorder 的存储概览与 NativeReportViewModel 的报表快照生命周期不同，各自表达首读、成功、不可用和重试。保留旧快照时一起保留其范围及更新时间。只把提供方能辨认的失败写为失败；保留现有关闭取消和迟到结果丢弃。无快照时禁用依赖其内容的破坏性操作；导出仅使用就绪的同一范围。
3. **先做语义，再调视觉足迹。** Toggle 使用业务标题或定向标签配对，多个控件分别命名；PanelCapsulePicker 给出组名、选中 trait 与等宽稳定命中区。选中前景与模块色分开。RowHeaderPills 局部调字，更新 MetricCellSizing 的受影响登记。CPU 行头优先保留单一激活路径，避免 Button 与原 tap 同时触发，保留排序动作、隐藏明细焦点与滚动恢复。
4. **把浮层视为带生命周期的所属窗口。** 在 PinnedPanelController 与 QuickToolsPopoverPresenter 间传递当前展示关系；外点和失焦两条判断共用归属，浮层关闭后及时撤销。Escape 先询问拖动，再退浮层，再退可收起的活动临时面板。使用当前宿主响应链；后台全局监听、粗略延时关闭和全面放宽外点判定都会影响其他应用或普通面板。
5. **原生操作复用同一执行入口。** 快捷键保存前复用当前 KeyboardShortcuts 可用的系统/应用菜单冲突信息，另覆盖标准 ⌘Q；检出冲突时保留旧绑定。登录项用系统状态决定是否引导去“登录项”，只有已知状态才提供相应指引。ReportWindowPresenter 的现有打印/HTML 动作从活动报表窗口暴露给菜单，按钮和菜单共用忙碌、关闭、时段校验。
6. **视觉修改只跟语义走。** P/E 的图例、曲线与预览环取同一主题角色，平衡 GPU/内存仅校正模块身份色；峰值线型、压力状态、两套配色及经典毛玻璃继续独立。复制反馈参考已有显示器档案，避免逐格常驻提示。现行目录实际覆盖 zh-Hans/en；本次新增和变更文案须覆盖这两种实际界面。既有 localization-completeness 另有日语契约，变更涉及其键时同步补目标键的翻译；全库历史缺口不混入本次验收。

## Risks / Trade-offs

- 异步晚回调覆盖当前范围 → 用慢读、失败后重试、切时段、关窗后返回的确定性输入验证。
- 面板有多个原生宿主，点击成功不等于键盘或 VO 成功 → 分别记录物理指针、默认辅助动作、键盘及真实朗读。焦点不可因每秒采样丢失。
- 全局快捷键/菜单误作用于前台应用 → 先留旧绑定，验证取消或无效保存；Esc、⌘P 均按各自宿主和所有权处理。
- 活跃 change 重叠 → `panel-long-press-reordering` 保持拖动取消/复制/展开既有契约；`improve-statistics-experience` 已含排行与本地化；`native-statistics-report` 已含工具栏导出。实施前复核这些位置的当前差异，本 change 仅接上述增量；共同测试可引用，不代替其他 change 的验收。
- 设备或签名不可用 → 夹具结果和原生结果分列。特别保留 15/26、两渠道、VoiceOver、物理显示器和正式登录项/打印的未测单元；发布结论只覆盖实际验证的组合。

## Migration Plan

不修改历史数据或偏好格式。按任务批次分别测试和回退。回退展示分支不回写快照；撤回菜单/按键处理要释放监听、结束临时会话；隐藏实验行不改写保存值。若新的原生观察推翻某一候选，只调整该切片并记录证据，其他批次可继续。

## 快捷键范围调整

2026-11-04 用户确认先完成已知冲突保护，实际注册失败另立变更。当前 KeyboardShortcuts 未公开注册结果，本 change 仅检查明确的标准、系统与应用菜单冲突，不修改依赖或自建注册适配。

## 普通菜单栏 Esc 的原生反馈修正

用户在本次实现的隔离验收版实测确认：普通主面板空闲时 Esc 不收起。早先“由系统响应取消即可”的假设没有覆盖共享根视图已消费该命令的情形。保留原有取消层级，在普通宿主空闲时显式调用现有关闭入口；该入口负责系统会话取消与重入门控。此修正不增加全局监听，不改变状态项点击分流。实际修正版结果待复测记录。

## 主行焦点提示

主行鼠标点击保持原有圆角卡片观感；键盘或辅助导航聚焦时显示行内圆角轮廓。保留可聚焦和 Space 激活，替换默认矩形蓝框。沿用现有行卡圆角及主题前景，不扩大命中区、布局宽高或常驻装饰。

## 常驻隐藏内容的键盘边界

折叠明细和非活动双页内容继续常驻参与自然尺寸测量，但必须同步退出键盘操作。使用标准 isEnabled 环境在明细边界禁用，跨独立 NSHostingView 显式传递并纳入环境缓存键；自定义 focusable 值遵守该状态。窗口动态重算 key-view loop。此调整保持已有布局和动画链，未添加全局按键拦截。
