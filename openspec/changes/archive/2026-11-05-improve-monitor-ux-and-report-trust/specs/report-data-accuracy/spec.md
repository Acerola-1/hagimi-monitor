## ADDED Requirements

### Requirement: 告警区间与设备说明可本地化
报表 SHALL 以当前语言呈现告警有效起止、设备供电及传感器可用性。
#### Scenario: 已结束和仍在进行的告警
- **WHEN** 中文或英文报表展示跨日事件或仍在进行的事件
- **THEN** 起止分别与观测记录相符，结束为空时采用最后观测，无内部格式键；区间与连续高负载时长可区分。
#### Scenario: 无电池或不可读取传感器
- **WHEN** 报表展示交流供电、桌面机或受限硬件
- **THEN** 文案使用当前语言，说明用户可理解的能力边界。

### Requirement: 所选时段风扇状态
热报表 SHALL 区分无物理风扇、不可读取、无有效历史、实测零与非零历史。
#### Scenario: 有风扇且可读取
- **WHEN** 所选时段无有效风扇记录、实测最高为零或实测非零
- **THEN** 分别显示无记录、该时段记录为零、对应均值/峰值；缺测不得显示 0 RPM。
#### Scenario: 能力受限
- **WHEN** 明确无物理风扇或当前渠道无法读取
- **THEN** 显示对应硬件或能力说明，不推断风扇停转。

### Requirement: 原生报表标识快照时效
报表 SHALL 区分加载、成功但缺样本、首次失败和已有快照的刷新失败。
#### Scenario: 首次不可用或刷新失败
- **WHEN** 数据提供方明确不可用
- **THEN** 显示可重试说明；若展示旧快照，标明其时段、更新时间与失败状态，重试成功后清除提示。
#### Scenario: 空结果与晚回调
- **WHEN** 有效读取返回空时段，或先前请求晚于切换时段/关闭窗口返回
- **THEN** 空时段维持无样本语义，过期请求不得覆盖当前结果。

### Requirement: 跨窗口的类别色语义
同一主题中，报表 SHALL 与预览、实时面板对同一 CPU 核类别及模块身份使用一致的颜色角色。
#### Scenario: 对看图例与仪表
- **WHEN** 用户从预览或面板进入 CPU 图例、从总览打开 GPU 或内存详情
- **THEN** 同一类别的色义不反转，图例与系列匹配，平均/峰值与压力档位仍可区分。
