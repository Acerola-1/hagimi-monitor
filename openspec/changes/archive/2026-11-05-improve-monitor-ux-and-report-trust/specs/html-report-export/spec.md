## ADDED Requirements

### Requirement: 前台报表的文件菜单命令
原生报表 SHALL 在文件菜单提供打印（⌘P）与导出 HTML 命令，并与工具栏共享就绪状态和所选时段。
#### Scenario: 就绪的报表为活动窗口
- **WHEN** 用户通过菜单、⌘P 或对应的工具栏按钮发起操作
- **THEN** 启动相同的打印或保存流程，输出内容及时间范围一致，取消后可重试。
#### Scenario: 失焦或忙碌
- **WHEN** 只有设置窗口在前、报表未就绪或已有导出/打印处理中
- **THEN** 对应报表专用命令不可执行，重复触发不会创建第二个会话。
