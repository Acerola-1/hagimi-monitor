## ADDED Requirements

### Requirement: 快捷面板与其工具浮层属于同一次交互
快捷面板 SHALL 将自己的可见工具浮层计入内部交互区域，同时继续识别真实外部点击。
#### Scenario: 未钉住时操作工具
- **WHEN** 用户在工具浮层内点击说明文字或启停可安全切换的工具
- **THEN** 父面板与浮层持续可见，控件操作完成；真正点击外部时临时态按既有规则关闭。
#### Scenario: 已钉住
- **WHEN** 用户操作或关闭工具浮层
- **THEN** 钉住意图保留，关闭子层后可继续操作父面板。

### Requirement: 快捷面板的局部取消
面板接收键盘操作时 SHALL 按当前操作层级响应 Esc；前台其他应用保有自己的取消命令。
#### Scenario: 临时面板空闲与分层取消
- **WHEN** 用户在活动临时面板按 Esc
- **THEN** 如有在途拖动则仅取消拖动，否则如有浮层则仅关闭浮层，否则收起临时面板；一次按键最多退出一层。
#### Scenario: 钉住或系统接管关闭
- **WHEN** 空闲钉住面板收到 Esc 或 macOS 27 菜单栏系统会话已响应取消
- **THEN** 钉住状态保留，系统会话只关闭一次。
