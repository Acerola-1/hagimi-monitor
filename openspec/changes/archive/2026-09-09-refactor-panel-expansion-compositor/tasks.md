## 1. 建立基线与可观测性

- [ ] 1.1 使用 `HAGIMI_PANEL_AUTOTEST` 分别记录 App Store 与 Direct scheme 的现有展开/收起基线，保存 60 Hz、ProMotion、低电量模式和高 CPU 负载下的主线程耗时、丢帧、窗口高度、内容高度与内存峰值，作为后续门禁的同机对照。
- [ ] 1.2 为新动画管线补充低开销 signpost 与调试断言，覆盖 display-link 回调、弹簧采样、几何求解、窗口提交、图层提交和 hosting view 布局次数；验证未开启自动测试或性能采集时不会产生持续性驱动。
- [ ] 1.3 增加仅供开发验证的架构切换入口，使旧管线和新 compositor 能在同一构建中 A/B 对照；验证默认发布配置仍选择已确认稳定的实现，并且开关不进入用户可见文案。

## 2. 实现统一运动与几何内核

- [ ] 2.1 定义与视图框架无关的 `PanelGeometrySnapshot`、卡片自然尺寸输入和面板约束输入，使卡片可见高度、兄弟卡片位置、footer、滚动偏移及窗口高度都由同一快照导出。
- [ ] 2.2 实现纯函数几何求解器，把 6 pt 行间距、10 pt 底边距、固定 header/footer、面板最大高度和滚动上限编码为结构约束；用单元测试覆盖展开、收起、多个展开项、面板封顶及空列表。
- [ ] 2.3 增加属性化测试或等价的批量随机测试，对不同卡片数量、自然高度和展开相位验证所有相邻卡片间距恒为 6 pt、footer 到窗口底缘恒为 10 pt，且任何输出都不存在负尺寸或非有限数值。
- [ ] 2.4 实现基于绝对时间戳的闭式二阶弹簧状态，状态同时包含位置和速度，并支持从任意采样时刻重定向目标；测试连续快速反向时位置、速度均连续且结果不依赖 display-link 回调频率。
- [ ] 2.5 实现展开相位的边界接触规则：到达 0 或 1 时只消除继续越界的速度分量，不在区间内部钳制；测试高初速度、欠阻尼过冲和连续反转不会揭示自然内容边界之外的区域。
- [ ] 2.6 实现多卡片目标向量与确定性的自动揭示目标选择，规定最后一个新展开且处于视觉顺序最下方的卡片为滚动目标；测试同一事务内多项变化不会生成第二套独立动画。

## 3. 用原生三卡片样机验证系统边界

- [ ] 3.1 建立最小原生样机：真实 `NSPanel`、三张固定自然尺寸的 SwiftUI hosting 岛、生产同款 live `NSVisualEffectView` 材质、原生窗口阴影及 AppKit 裁剪容器；确认展开期间 hosting 岛本身不改变尺寸。
- [ ] 3.2 实现样机的单一 `CADisplayLink` 协调器，每次回调只采样一次闭式弹簧并同步应用窗口 frame、卡片裁剪、兄弟位置、footer 和滚动偏移；用 signpost 验证一帧内不存在第二个动画时钟或 SwiftUI 状态写入。
- [ ] 3.3 在样机中实测 `NSWindow.setFrame(_:display:)` 的 `display: false` 与现有提交方式，依据重入布局次数、WindowServer 提交耗时和视觉正确性选择生产策略并把结论写入设计注释或测试记录。
- [ ] 3.4 验证样机在展开、收起、动画中暂停截图及高频反向时始终满足 6 pt/10 pt 几何约束，且内容只由下边界卷出、没有缩放、拉伸、空白撕裂或裁切正文。
- [ ] 3.5 验证 live material 会随窗口后方内容和窗口移动持续变化，`hasShadow` 保持系统原生效果，透明区域不会扩大事件边界，点外关闭与 pinned 面板后方点击均与真实窗口轮廓一致。
- [ ] 3.6 在 60 Hz、ProMotion、低电量模式和高 CPU 负载下对样机运行自动回归；仅当 SwiftUI 动画期递归布局被消除、主线程预算相对基线显著下降且没有交互或视觉降级时，才进入生产迁移。

## 4. 搭建生产级 PanelCompositor 容器

- [ ] 4.1 实现 `PanelCompositorView` 及稳定 item descriptor，划分固定 header、可滚动 body viewport、卡片 clip host 和固定 footer，并由 AppKit 明确管理顶层 frame，而不把动画高度提案传回根 SwiftUI `VStack`。
- [ ] 4.2 实现可复用的固定自然尺寸 `NSHostingView` 岛封装，在稳定 identity 下缓存自然尺寸，只在内容结构、宽度、语言、外观或字体环境真实变化时重新测量；验证普通指标采样不会触发自然尺寸重测。
- [ ] 4.3 为每个卡片岛配置顶部对齐的合成裁剪边界，保证详情内容始终按 1:1 像素比例渲染；验证 layer tree 中没有 snapshot、`shouldRasterize`、位图缓存或几何缩放。
- [ ] 4.4 把统一运动协调器接入 `PanelCompositorView`，确保 display-link 生命周期只覆盖未收敛的弹簧，并在隐藏、销毁、Reduce Motion 同步路径和应用退出时正确停止。
- [ ] 4.5 复原鼠标命中、键盘焦点、VoiceOver 顺序与可访问性隐藏规则：裁剪之外的详情不可命中或聚焦，展开后的控件保持真实视图交互；增加自动化检查并完成手动键盘/VoiceOver 验证。
- [ ] 4.6 让菜单栏瞬态面板与 pinned 面板共享同一 compositor 和运动语义，同时保留各自的顶部锚定、屏幕边界修正、位置持久化、点外关闭和窗口层级行为；分别运行两种宿主的交互回归。

## 5. 迁移卡片与嵌套详情

- [ ] 5.1 为现有顶层卡片建立 descriptor 映射和稳定 identity，把 header、摘要区、详情自然高度及展开目标从 `MonitorPanelView` 的动画布局中分离；验证折叠与展开静止截图和现有版本一致。
- [ ] 5.2 先迁移结构一致的 CPU、GPU、内存、存储等指标卡片到独立 hosting 岛，保留所有 `MonitorPalette`、14 pt 连续圆角、28 pt 详情缩进和静态指标格规则；运行相关快照、宽度审计与交互测试。
- [ ] 5.3 迁移网络、电池、风扇等包含图表、列表或动态指标的卡片，确认采样数据只更新岛内渲染内容，不会改变顶层容器的动画几何或唤起额外 display link。
- [ ] 5.4 迁移显示器控制卡及其嵌套归档编辑器，把嵌套可见高度纳入同一几何快照；通过样机数据决定显示器区域使用单一 hosting 岛还是进一步拆岛，并验证 App Store/Direct 编译边界及无显示器、单显示器、多显示器场景。
- [ ] 5.5 处理动画过程中发生的真实几何失效事件，包括语言、面板宽度、字体环境、显示器集合及结构化内容变化：从当前 presentation 几何重新测量并重定向统一状态，验证没有跳帧、速度重置或间距破坏。

## 6. 合并封顶滚动与用户滚动

- [ ] 6.1 在 AppKit body viewport 中实现面板最大高度封顶，窗口高度、文档高度和 clip bounds 均从同一几何快照计算；测试从未封顶跨入封顶以及从封顶返回自然高度的连续性。
- [ ] 6.2 把自动揭示滚动偏移作为统一运动状态的派生量或同一目标向量分量，移除 SwiftUI `ScrollViewReader.scrollTo` 的独立弹簧；验证多项同时展开时只执行一次确定性滚动。
- [ ] 6.3 定义动画中用户滚轮/触控板输入的接管与重基准规则，使手动滚动从当前 presentation offset 连续开始并取消或重定向自动揭示；测试高频滚动、反向展开和触控板惯性不会产生 offset 跳变。
- [ ] 6.4 验证 header/footer 始终固定、最下方目标卡片可见、body 内容不越过裁剪区域，并在每一帧继续满足 footer 到窗口底缘 10 pt 的约束。
