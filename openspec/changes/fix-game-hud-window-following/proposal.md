# Proposal

## Why

窗口化游戏移动时，独立 HUD 持续追赶窗口仍有可见拖尾，原连续跟随候选的真实体验未通过。改为检测到移动后隐藏、停稳后在新位置恢复，避免拖动过程中的脱离与跳跃。

## What Changes

- 检测目标窗口真实边界变化（移动、缩放和跨屏），立即临时隐藏 HUD，拖动期间不呈现追赶位置。
- 鼠标松开且边界稳定后，在最新可靠位置恢复；普通点击不触发已显示 HUD 的隐藏。
- 临时隐藏保留浮窗、窗口身份、最新读数和历史，所有内容/测帧/设置/轮询回调统一遵守移动显示门控。
- 移除本 change 的屏幕逐帧追赶路径，以有限频率检查移动和停止；失焦、排除、关闭或目标失效仍结束会话。
- 更新回归测试、原生验收和资源门控说明，不增加录屏、辅助功能或输入监控授权。
- 四个角的卡片采用紧凑外边距，显式卡片与回退卡片一致；顶部横条容量边距独立保留。

## Capabilities

### New Capabilities

- `game-hud-window-tracking`: 目标窗口移动检测、临时隐藏、停稳恢复及生命周期门控。既有 `game-hud` 仍位于未归档 change，本次沿用其身份、布局与数据合同，仅增加临时隐藏语义。

### Modified Capabilities

无。

## Impact

Direct 的窗口定位器、跟踪器、会话控制器、协调器与浮窗控制器，相关测试及开发文档。删除本 change 尚未提交的显示同步时钟。保留现有游戏识别、采样频率、偏好、样式和中英文文案；不修改同期菜单栏工作。App Store 不编译该目录。
