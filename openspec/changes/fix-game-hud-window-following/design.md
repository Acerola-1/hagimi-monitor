# Design

## Context

动机见 proposal.md。先前 60 Hz 和屏幕同步连续跟随候选均未达到用户预期；已有定位身份校验和两样式布局可复用。当前所有呈现入口需要统一的临时隐藏门控，避免快照或每秒发现恢复旧 HUD。既有 game-hud 合同的普通隐藏仍结束专用工作，本 change 将移动期隐藏定义为保留会话的短暂显示抑制。

## Goals / Non-Goals

**Goals:** 检测真实窗口变化后隐藏，拖动中持续抑制呈现，停稳后在新位置一次恢复；普通点击不闪烁，两个样式、缩放和跨屏一致。

**Non-Goals:** 继续逐帧追赶、推算鼠标位移、注入第三方窗口、请求新系统授权，或更改硬件采样和 FPS 口径。

## Decisions

1. **身份发现与移动检测分离。** 保留每秒完整选窗，已确认 ID 只查单窗口。定位结果同时保留原始边界和裁剪后的可见矩形；使用原始边界判断移动，避免窗口在屏幕外移动却因可见交集不变而漏判。跨屏仍选择最大可见交集。
2. **有限频率状态机。** 已确认前台目标静止时 20 Hz，鼠标按下或移动未结束时 30 Hz。检测到边界变化即进入移动状态；鼠标按住时即使暂时停下也不恢复，松开且最后一次边界变化已稳定 180 ms 后退出。无鼠标的程序移动按稳定时间恢复。首次确认目标时若鼠标仍按住，先等待释放与稳定，防止在缩放途中重新发现目标而闪现。停止/换目标丢弃旧回调；移除显示同步时钟，不维持逐帧追赶。
3. **完整发现不能覆盖移动状态。** 同一窗口的新定位结果必须进入同一状态机，不能先更新会话几何、再直接显示。切换窗口身份重置状态机。移动状态与窗口资格分开：保留可跟踪资格，独立判断可呈现资格。
4. **临时隐藏保留会话。** panel 仅 orderOut，保留宿主与尺寸；协调器继续按原节奏缓存读数/帧统计和历史但不提交视图、不移动隐藏浮窗、不重启采样。恢复时使用最新内容与最新布局。失焦、排除、总开关关闭、窗口失效或放不下仍走真正 teardown，取消恢复资格。
5. **全部呈现路径统一门控。** 状态、低频发现、几何、快照、帧统计、位置/样式/透明度与名单回调都复核当前资格和移动状态。先隐藏再通知外部，临时隐藏不得触发布局不可用的停止逻辑。恢复条件改变或新一轮移动会延后恢复。
6. **验证。** 虚拟时钟验证普通点击、持续移动、中途停顿、松手、反向、缩放、程序移动、完整发现和晚到回调；真实 panel/协调器验证快照和设置回调不会提前显示，恢复保留宿主且读到最新内容。构建两渠道、运行相关测试并严格校验；原生拖动需用户实际反馈，自动工具不能拖动真实标题栏的既有限制不作为通过证据。

## Risks / Trade-offs

- 初始检测仍受系统查询和调度影响 → 不承诺移动同一帧隐藏；检测后整个移动过程保持隐藏。
- 稳定阈值过短会闪现，过长会拖慢恢复 → 参数集中登记并通过含暂停的状态机测试，原生复测后再调整。
- 临时隐藏与失效混淆 → 独立显示抑制状态；失效清除身份与恢复条件。
- 短暂隐藏继续保留读数和测帧 → 只在原本合格的前台会话中维持，任何资格撤销即停止，不把它推广为后台常驻工作。
