# Proposal: 逐屏连接控制与无可见屏救援

## Why

用户需要不拔线即可逐一停用/恢复内置与外接屏。真实测试发现原自动停用记忆和依赖 DDC 沉降的通知链路会造成拔掉外接屏后内置屏仍黑屏，因此当前方案以恢复优先和不自动重放停用为准。

## What Changes

- 仅在 GitHub 下载版、Apple 芯片 Mac 提供逐屏软断开；App Store 不包含连接实现或交互。
- 启动读取当前状态，清理旧停用记忆。新停用只来自用户明确操作；重启/唤醒/插线不自动再次停用。
- 建立独立于 DDC 门禁的拓扑救援，物理屏移除时优先恢复本应用停用的屏；在存在停用屏时用轻量连接检查补偿漏通知。
- 保留至少一块可用物理屏，虚拟、远程或合盖屏不抵扣保护。软件启动和退出不改变屏幕开关；只有运行中失去最后一块可见屏，或用户明确操作时才救援或切换。
- 按钮传入明确启用目标，避免旧 UI 状态导致反向动作；外观沿现有蓝灰、中性材质和紧凑布局。
- 停用卡片只保留标题和启用动作；主行继续显示逐屏亮度；在线参数/档案保持原交互。
- 保留稳定身份、恢复拥有权、原子日志及无冲突镜像恢复，不导入第三方完整项目。

## Capabilities

新增 `display-connection-control`；现有参数控制与面板材质合同沿用，只有本变更明确覆盖的停用卡片与生命周期行为更新。

## Impact

Direct-only 连接模型、桥接、协调器及现有 DisplayControlController/DisplayPersistence/DDCEnvironmentGate；共享 DisplaySection、显示器设置和 AppDelegate 按渠道条件接线。中英本地化，不增加语言。
