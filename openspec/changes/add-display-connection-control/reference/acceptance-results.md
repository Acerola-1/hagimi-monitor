## 恢复操作与错误解释

1. 日常恢复：逐屏“启用”；成功后清除该屏停用偏好。
2. 没有批量恢复。每块屏用自己的启用。没有可用物理屏时，运行中或下次启动会救援本应用停用的内置屏。
3. 异常启动：先保持自动暂停；确认屏幕可见后才选择恢复自动应用。该动作保留偏好并重新核验条件，不重放旧事务。
4. 正常退出会有界等待恢复；系统同步调用不能被强制取消，应用终止等待最长八秒，超时日志保持未完成供下次启动救援。

- 能力不可用：无连接写入，原显示信息/参数能力继续运行。
- 身份不确定：不能唯一映射当前设备，拒绝该记录的写入，不能通过旧编号强行恢复。
- 最后屏保护：保留偏好但不执行新的不安全停用。
- 等待稳定/成员缺席：连接与镜像恢复分别反馈；已连接的屏可以先使用，镜像日志保留到可安全恢复。
- 状态未确认：调用虽返回成功，观察状态仍未达标；不显示成功，保留救援日志。
- 镜像冲突：优先较新的外部设置，连接仍恢复，原镜像不再在后续事件中强制覆盖。
- 存储故障：禁止新增停用，单屏启用仍可尝试；损坏文件不会被自动覆盖。
