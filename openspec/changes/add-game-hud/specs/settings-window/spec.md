# settings-window Delta for game-hud

## ADDED Requirements

### Requirement: Game HUD 设置页

设置窗口 SHALL 在侧栏「扩展」分组提供 Game HUD 设置页，不改变既有模块选择与菜单栏指标设置。设置组顺序为总开关、监控项目、游戏名单、左右布局；官网版另显示受控启动与官方 HUD 说明。

#### Scenario: 总开关与实际状态
- **WHEN** 用户在设置页切换 Game HUD 总开关
- **THEN** 它与主面板工具区共用同一设置来源
- **AND** 关闭时立即隐藏硬件 HUD
- **AND** 开启但无匹配游戏或可靠目标窗口时，明确显示“已启用，当前未显示”类状态，不误报正在监控

#### Scenario: 指标选择
- **WHEN** 用户查看指标列表
- **THEN** 只显示本渠道和本机已确认可用的首版硬件项目
- **AND** CPU/GPU 占用、整机内存和 GPU 驱动聚合内存按实际能力提供，整机功耗仅在有真实读数时可选
- **AND** 官网版可读时追加 CPU/GPU 分项功耗与 CPU 温度；App Store 版不显示其不可读项目
- **AND** 不出现 GPU 温度、风扇和 0.1% Low
- **AND** 勾选状态独立持久化，不受主面板模块选择影响

#### Scenario: 应用名单
- **WHEN** 用户查看游戏名单
- **THEN** 可查看保守的自动候选、添加/移除用户指定的 bundle ID、排除候选
- **AND** 排除优先于添加和候选
- **AND** 不在每次进入设置页时全量枚举已安装应用

#### Scenario: 左右布局
- **WHEN** 用户查看布局设置
- **THEN** 只能选择左或右，默认右；不提供四角及像素级偏移配置
- **AND** 文案解释硬件 HUD 视觉上位于目标游戏窗口的所选侧下角，窗口无法确认时隐藏

#### Scenario: 官网版受控会话修改布局
- **WHEN** 官网版已受控启动的游戏仍在运行，用户修改左/右侧
- **THEN** 两块 HUD 当前侧边不变，设置提示下次由本应用启动该游戏时生效
- **AND** 普通硬件会话可即时调整硬件 HUD
- **AND** 不能把未受控启动的官方 HUD 状态显示为已配置或已检测

#### Scenario: 渠道化辅助
- **WHEN** 官网版显示设置页
- **THEN** 可说明并进入用户主动的受控启动流程，展示该游戏启动链是否已验证可传官方配置与逐帧数据
- **AND** 官方 HUD 的固定元素预设与硬件项目勾选分离
- **WHEN** App Store 版显示设置页
- **THEN** 不出现受控启动、官方 HUD 代开或 FPS 统计入口

### Requirement: Game HUD 文案本地化

Game HUD 设置页所有用户可见标题、指标、状态、能力限制与“下次启动生效”提示 SHALL 接入 `Localizable.xcstrings` 并补齐中英翻译；复用已有指标名称 key，不新增同义 key。

#### Scenario: 英文环境
- **WHEN** 系统语言为英文
- **THEN** 设置组、游戏名单、受控启动状态与布局提示均显示英文
- **AND** Metal、FPS 等专有名词保持正确语义
