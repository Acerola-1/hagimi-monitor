## Purpose

子进程采样（网络与 CPU TOP 列表依赖外部命令行工具）的挂起防护：单个子进程卡死不得堵塞采样队列，采样管线在异常系统状态下保持出数。

## ADDED Requirements

### Requirement: 子进程采样具备超时终止能力
通过外部命令行工具获取进程数据的采样，SHALL 对每次子进程执行施加有界超时；超时后 SHALL 终止该子进程并跳过本次采样结果，不得无限等待。

#### Scenario: 子进程正常退出
- **WHEN** 子进程在超时窗口内正常输出并退出
- **THEN** 采样照常解析输出并更新列表
- **AND** 采样耗时与无防护时相当

#### Scenario: 子进程挂起不退出
- **WHEN** 子进程因系统异常状态挂起、超过超时窗口仍未退出
- **THEN** 该子进程被强制终止
- **AND** 本次采样被跳过（列表保留上一次有效结果）
- **AND** 后续排队的采样任务正常执行，采样队列不堵塞

### Requirement: 采样队列不因单次采样失败而停摆
任一类型进程采样（网络或 CPU）的子进程挂起，SHALL NOT 阻塞其他类型进程的采样、统计入库或面板刷新。

#### Scenario: 网络采样挂起时其他采样正常
- **WHEN** 网络 TOP 采样的子进程挂起并被超时终止
- **THEN** CPU/内存/GPU/磁盘 TOP 列表继续按各自节奏更新
- **AND** 统计入库与面板刷新不受影响
