## Purpose

Provides a macOS native statistics report window using AppKit and SwiftUI to visualize system metrics, hardware inventory, process rankings, and events without WebKit overhead.

## ADDED Requirements

### Requirement: 原生独立报表窗口与生命周期管理
应用 SHALL 提供基于 macOS 原生窗口（AppKit + SwiftUI）的统计报表界面，彻底替代日常查看时的常驻 WKWebView 方案，并在窗口关闭时释放专用图表与数据资源。

#### Scenario: 打开原生报表窗口
- **WHEN** 用户通过应用菜单或设置面板点击打开报表
- **THEN** 应用展示原生报表窗口，窗口采用经典毛玻璃风格与系统外观跟随
- **AND** 报表直接通过后台读取强类型 Swift 数据模型进行首屏渲染，不拉起 WKWebView 或 WebKit 辅助进程

#### Scenario: 关闭报表窗口释放资源
- **WHEN** 用户关闭报表窗口
- **THEN** 停止实时读数定时器与主题监听，并清空当前报表窗口持有的视图和数据快照
- **AND** 保证内存不会在多次打开和关闭后单调递增

### Requirement: 强类型数据模型与全模块统计展示
原生报表窗口 SHALL 支持全量指标模块呈现，包括系统健康评分、活动热力图、CPU（含 P/E 核与负载分布）、GPU（含分布与显存）、内存（构成与压力）、网络（吞吐与每日柱状图）、磁盘（吞吐与每日柱状图）、功耗与电池（含历史健康与循环）、热状态与风扇、应用排行（含能耗与高负载告警）、事件流、数据明细表、洞察建议及本机硬件规格。

#### Scenario: 时间范围切换与粒度适配
- **WHEN** 用户在顶部选择「今日」、「近 7 天」、「近 30 天」、「近 1 年」或自定义日期范围
- **THEN** 界面根据时间跨度自动选取对应粒度数据（分钟、小时或日）并基于正确的加权平均、峰值与累积值刷新各模块
- **AND** 「今日」视图自动折叠跨日聚合板块（如活动热力图、网络每日、磁盘每日）

#### Scenario: 悬停读数与无数据状态
- **WHEN** 用户在图表区域悬停光标
- **THEN** 图表提供准确的时间与数值指示，并清晰区分缺失值（—）与真实 0
- **AND** 当指标在硬件或沙盒限制下不支持时（如沙盒下的进程网络排行、无电池的台式 Mac、无风扇机型），相应区域展示明确的空状态或语义隐藏

### Requirement: 实时运行状态与硬件侧栏联动
原生报表窗口 SHALL 为各监控模块（CPU、GPU、内存、网络、磁盘、电源）提供右栏硬件规格与实时状态卡片，并提供独立的「本机」硬件全景分类浏览。

#### Scenario: 实时状态轻量推送
- **WHEN** 报表窗口处于可见、未最小化且未被完全遮挡的状态，应用也未隐藏
- **THEN** 右栏「运行状态」每秒只从当前硬件模块获取最新瞬时读数并局部刷新
- **AND** 相同读数不重复发布，实时刷新不触发历史趋势图表或重度聚合重算
- **AND** 当窗口最小化、完全遮挡、切换 Space、应用隐藏或当前模块没有实时栏时停止刷新
- **AND** 恢复可见或切换到有实时栏的硬件模块后立即获取一帧

#### Scenario: 模块锚点跳转
- **WHEN** 外部组件携带锚点打开报表（如从设置页高负载卡片跳转应用区或内存区）
- **THEN** 原生报表窗口平滑定位至对应模块位置
