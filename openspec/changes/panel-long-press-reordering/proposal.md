# Proposal

## Why

面板模块和展开区指标目前按固定顺序显示，用户无法按自己的关注顺序组织信息。希望直接在面板中长按拖动，同时严格保留已审计的指标半行／整行宽度，不以缩放或改变格宽换取任意排布。

## What Changes

- 普通与置顶面板支持长按顶层概览行，移动整个模块；显示器区块参与，底部三个按钮固定。
- 模块内的指标格仅在同模块、同分页、同一连续指标区中排序；支持半行与整行交错，指标固有宽度不变。CPU 温度／热压力合并行作为一个单元，电池供电诊断行在所属分页内可排序。
- 拖动时提供浮起预览、占位和相邻项让位；有效落点释放后才保存。无效落点、面板外释放及 Esc 取消均恢复原状，滚动边缘支持自动滚动。
- 顺序按稳定 ID 持久化；隐藏或暂时不可用的项目保留位置。新项目按默认相对顺序插入，保留已有用户排序。
- 提供最近一次排序的撤销、右键及辅助功能上移／下移，以及每个模块设置页的“恢复本模块指标布局”。不提供全局或顶层顺序重置，也不新增设置内排序界面。

## Capabilities

### New Capabilities

- `panel-reordering`: 面板内可排序范围、拖动反馈、落点、持久化、撤销及辅助操作。

### Modified Capabilities

- `monitor-panel`: 将“半行指标先于整行指标”的固定行序改为按用户顺序排布，仍使用静态宽度登记并保留不可排序组件的结构位置。
- `settings-window`: 在各模块设置页增加仅恢复本模块指标顺序的操作。

## Impact

- 面板模块与指标渲染、混合跨度布局、展开几何／滚动及普通／置顶面板事件处理。
- `MonitorSettings` 的顺序存储与迁移、按 ID 排序的展示路径；不改采样顺序或指标宽度登记／最坏值审计契约。
- 模块设置页、本地化文案、确定性排序／布局测试及双渠道原生交互验证。
