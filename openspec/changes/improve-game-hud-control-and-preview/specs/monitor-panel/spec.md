# monitor-panel Spec Delta

## ADDED Requirements

### Requirement: Game HUD 设置改进保持主面板不变

本变更 SHALL 保持主面板基线布局和内容，不增加 Game HUD 管理入口、规则说明、目标状态行、候选确认或上下文控制区。应用添加、排除和移出黑名单 SHALL 统一在 Game HUD 设置页完成。

#### Scenario: 普通打开面板
- **WHEN** 没有游戏或任何已识别应用位于前台，用户打开菜单栏面板
- **THEN** 主面板呈现原有监控内容，不因总开关开启而插入 Game HUD 说明或入口
- **AND** 主面板尺寸不会因为新增 HUD 管理内容变大

#### Scenario: 显示 HUD 或存在误判时打开面板
- **WHEN** 当前应用显示 HUD、曾被识别或已被排除，用户打开主面板
- **THEN** 不新增针对该应用的管理行、确认按钮或状态提示
- **AND** 用户通过原有设置入口进入 Game HUD 设置管理应用

### Requirement: 原有菜单栏操作与总开关入口保留

本变更 SHALL 保留原有菜单栏点击呼出主面板、设置入口、固定底部操作和已存在的 Game HUD 总开关入口；不得为新设置功能改变这些动作或在主面板显示首次开启说明。

#### Scenario: 菜单栏点击与重复呼出
- **WHEN** 用户点击菜单栏图标，关闭设置后再次点击，或切换应用后重新点击
- **THEN** 主面板按原有行为正常打开/关闭，已有设置入口可用
- **AND** 不因识别、扫描、黑名单或设置深层路由而失去响应

#### Scenario: 已有总开关动作
- **WHEN** 用户通过基线已存在的工具区总开关入口控制 Game HUD
- **THEN** 继续切换与设置同源的总开关，不新增管理界面或改变按钮原语义
- **AND** 如需规则说明，仅由设置页简短呈现，不向主面板插入文字块
