## 更新内容

### 中文

#### 新功能

- 新增游戏 HUD：当打开已识别的游戏时，屏幕上会自动显示硬件监控浮窗，实时显示 CPU 占用、CPU 温度、GPU 内存、内存与整机功耗。浮窗位于游戏窗口内侧下角，跟随游戏窗口移动与跨屏切换；游戏失焦或退出时自动隐藏。同时读取游戏帧率，支持 FPS、平均帧率、1% Low 与帧时间。已安装的游戏通过 Steam、Epic 与系统扫描自动识别，无需手动配置。监控项目、浮窗位置与游戏名单可在设置中调整；HUD 显示期间，面板与菜单栏图标会显示运行徽章。

### English

#### New Features

- New Game HUD: when a recognized game is opened, a hardware monitoring overlay is displayed automatically, showing live CPU usage, CPU temperature, GPU memory, system memory, and total system power. The overlay sits at the bottom corner inside the game window and follows window movement and display changes; it hides automatically when the game loses focus or quits. The game's frame rate is also read, supporting FPS, average FPS, 1% Low, and frame time. Installed games are detected automatically via Steam, Epic, and system-wide scanning, with no manual configuration required. Metrics, overlay placement, and the game list can be adjusted in Settings; while the HUD is active, the panel and menu bar icons show a running badge.
