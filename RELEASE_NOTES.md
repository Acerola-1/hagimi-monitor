## 更新内容


### 中文

#### 新功能

- 新增长期高负载进程监测，覆盖 CPU、GPU、内存和网络，并记录持续时长、平均值、峰值及负载档位分布。
- 新增进程高负载告警状态，支持进行中与已恢复事件、按应用合并展示，以及系统通知开关。

#### 报表与体验

- 统计报表增加长期高负载卡片和进程负载档位提示，展示时间范围、均值、峰值与占用分布。
- 设置页增加高负载告警查看、展开与统计打卡和使用概览相关界面。
- 提升进程图标持久化分辨率，改进报表中的图标回退逻辑与模块定位体验。

### English

#### New Features

- Added sustained high-load process monitoring for CPU, GPU, memory, and network activity, including duration, average usage, peak usage, and load-tier distribution.
- Added process high-load alert states with ongoing and recovered events, per-application grouping, and system notification controls.

#### Reports and Experience

- Added a sustained high-load card and process load-tier hints to statistics reports, showing time ranges, averages, peaks, and usage distribution.
- Added high-load alert browsing, expansion controls, and statistics check-in and usage overview surfaces to Settings.
- Improved persisted process icon resolution, report icon fallbacks, and report section navigation.
