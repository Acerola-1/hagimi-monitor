# 旧资产归档 (Legacy Assets)

## icons/ — 应用图标历史版本

| 目录 | 版本 | 说明 |
|---|---|---|
| `01-ai-neon-original/` | 初版 | AI 生成的满幅直角霓虹绿环(1024,无 Alpha),曾导致 macOS 15 启动台显示直角 |
| `02-rounded-neon/` | 第二版 | 圆角合规修复版母版:烘焙官方圆角矩形+透明边距+标准投影,保留原霓虹风格 |
| `03-flat-glass-layers/` | 第三版 | 扁平绿环液态玻璃版:Icon Composer 图层资产(ring/ring-light/dot)+icon.json+亮暗渲染预览 |
