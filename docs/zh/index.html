全方位掌控你的 Mac

七大监控模块，从菜单栏到详细面板，每一个数据都触手可及。

CPU 监控

GPU 监控

通过 IOKit 查询 GPU 利用率、渲染与分块性能，掌握图形负载。

内存监控

追踪内存压力、交换分区使用，智能检测内存压力等级变化。

存储监控

实时磁盘容量与 I/O 统计，支持外部卷检测与读写速率追踪。

网络监控

追踪上传下载速率，检测网络接口类型，获取公网 IP 地址。

电池与电源

电池健康度、充电功率、循环次数、温度全方位监控。
