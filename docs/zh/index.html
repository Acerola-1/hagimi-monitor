综合评估系统压力
精准反馈

负载环融合 CPU、GPU 与内存压力，通过 Softmax 聚合算法生成综合分数。颜色随负载状态实时变化——绿色空闲、青色工作、橙色繁忙、红色高压。

面板布局，随手编排

自定义排序

所有模块行与指标格支持长按拖动排序，拖起时浮起预览、落点实时归位；也可右键（触控板双指轻点）呼出菜单，按上下左右逐格移动，顺序随时可恢复。

不止监控

数据统计

运行数据分层聚合入库，在原生数据报表中查看趋势曲线、热力图、健康评分与历史走势；需要时也可导出独立 HTML 文件。

更多能力

快捷功能

键盘锁定、系统防休眠、屏幕不息屏——常用操作从面板一键开关，激活状态会在面板头部点亮。

仅 GitHub 直连版

外接显示器控制

直连版可通过 DDC/CI 调节外接显示器的亮度、音量和对比度。是否可用取决于显示器、线材和连接方式；不支持的控制项不会显示为可用。显示器信息两个版本都能看，这组控制不在 App Store 版里。
