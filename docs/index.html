状态变化，抬眼就能确认。

从菜单栏负载到展开后的详细指标，Hagimi Monitor 适合长时间常驻，也适合在风扇升速、卡顿或外接设备异常时快速排查。

01

负载环

菜单栏图标用颜色和环形进度提示综合压力，轻载、忙碌、高压能直接区分。

02

核心指标

CPU、GPU、内存、存储、网络、电池各自独立采样，状态变化不用打开活动监视器。

03

趋势图

CPU 与 GPU 使用率配有小型趋势图，短时间尖峰和持续高负载不会混在一起。

04

展开详情

需要追原因时，可以展开查看核心分布、显存、内存压力、卷信息、IP 和电池健康。

05

两套配色

平衡模式更安静，活力模式更醒目。两者都分别适配浅色和深色外观。

06

Direct 构建

非 App Store 构建可加入外接显示器亮度、音量和对比度控制，显示控制不进入沙盒版。

浅色、深色，各有两套面板风格。

平衡模式更安静，活力模式更醒目。系统外观切换时，面板会跟随当前环境保持清晰可读。

Details

常驻时收敛，需要时展开。

默认视图保留高频信息；点开模块后，再展示更细的排查数据。日常不占注意力，遇到问题时不用临时翻工具。

  • CPU 核心分布与实时频率
  • GPU 使用率、显存与图形状态
  • 内存压力、交换空间和存储卷详情
  • 网络地址、电池健康度与循环数
