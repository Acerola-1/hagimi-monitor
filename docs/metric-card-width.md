# 指标卡片宽度

普通明细卡片支持「自动」「半行」「整行」，每行最多两格。CPU 的温度和热压力仍合并为一个卡片；启动时间可与它并排。

## 设置方式

- 面板：右键点击指标卡片，在「卡片宽度」中选择。
- 设置：进入对应模块，在「监测项目」中点击每项右侧的宽度菜单。预览会随选择更新。
- 「卡片宽度恢复自动」仅清除该模块的宽度偏好，保留已选指标和排列顺序。

「自动」按实际内容、字体和可用宽度决定是否占整行；同一布局宽度与字体环境内保留遇到过的最大内容宽度，避免采样值变短后反复收回。调整面板宽度或字体、语言环境后重新计算。

「半行」和「整行」始终采用用户的选择。半行内容较长时沿用现有的缩放与省略规则，悬停可以查看完整标签和读数，无障碍读数也保留完整内容。

逐核图和独立功率流图保持专用布局。普通电源分项卡片和供电诊断支持宽度设置。

## 实现与兼容

- Direct 和 App Store 共用布局，无新增私有接口或依赖。
- 偏好保存在 `settings.panel.metricWidths`，以模块及稳定指标 ID 为键。未设置或无法识别的模式使用自动；内存主值切换继续沿用同一身份。
- 静态宽度登记只保留旧版默认排序和审计基准；实际布局采用 SwiftUI 内容的理想宽度。现有自定义顺序无需迁移。
- 拖动及方向移动按实际几何解析自动跨度。网格尺寸发生变化时刷新外层展开高度缓存，普通读数变化继续复用缓存。

## 验证

在 M3 MacBook Air、macOS 27.2.1、Xcode 27.2 上验证：

- 确定性测试覆盖自动换行、宽度/环境变更、稳定预算、手动覆盖、偏好重启恢复、内存身份映射和按模块恢复自动。
- 真实 SwiftUI 宿主覆盖最窄至最宽面板对应的网格宽度、半行热压力与启动时间并排、方向菜单、设置页预览，以及宽度切换和长读数出现后的展开高度更新。
- 中英文定向测试各 54 项通过，浅深色截图已检查；构建 Direct Debug/Release 和 App Store Release。

本次验证使用布局、设置和排序相关的定向测试，没有重新运行完整测试集。
