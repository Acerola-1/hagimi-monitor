# Hagimi Monitor 分阶段 UI/UX 优化计划

2026-11-04 · 规划基线 `d855b7d3` · 所有实施与补验均未执行

**优先投入 U01 控件语义、U04 告警本地化、U09 风扇历史、U10 首读与失败状态、U03 电源分页对比。** 前两项有现场证据，后三项有可指定输入或可计算的验收结果。U16 涉及更核心的主面板任务，要在第一天验证；若证实仅用键盘无法展开，则插入最早的可达性修复批次。全局快捷键 U17 同为 P1，但修改录制策略前需留存原绑定和正常组合的基线。

本计划以 U 为问题 ID，A/V/N 为原报告编号。相同 ID 下的 a、b 为可分别交付的改动切片。表中“小”指局部文案、样式或单个控件，“中”指涉及多处使用者、窗口命令或异步状态，“大”指跨宿主或系统版本的事件链。复杂度含验证成本。[综合报告与来源索引](2026-11-04-ui-ux-synthesis.md)

同一批次中的每个切片均可独立回退。共用文件的切片顺序落地，例如 U04b 的热状态文案与 U09 共用一个渲染分支，可先定 U09 状态语义再补翻译。涉及主面板的候选一旦复现为核心任务阻断，优先于 B3 的低风险文案收尾。暂缓和拒绝项不占排期。
